## 4. WHY THE NHS ID CARD IS BETTER + SAFER FOR UK CITIZENS (the pitch arm)
1. **Zero-password identity** — citizens never type a password; 2-of-3 of their own devices co-sign. Phishing a password becomes impossible because there is no password.
2. **Split-key = no single point of theft** — the identity key never exists whole on any device, server, or attacker's machine. Lose one device and nothing changes; compromise a server and there's no key to steal.
3. **Consent by design** — every consent/signing event produces a verify-able receipt (HMAC, idempotent, auditable). Citizens can see who touched what, when. NHS audit trail.
4. **AI-guarded** — the identity service is protected by a real AI security platform (injection defense, watermarking, anomaly) — not a compliance checkbox.
5. **Sovereign & accountable** — UK-owned IP, UK company, UK procurement answerability. No foreign-vendor lock-in for 50M citizens' identity.
6. **Compliance-first** — DTAC/DSPT/UK GDPR/DPIA built in, not bolted on; ISO 27001 roadmap ready.
7. **Registry-grade data foundation** — adopting the best of RaulWalter's data discipline (dedupe, unique identifiers, governance, cleansing) so the 50M master data is trustworthy from day one — exactly what an NHS national programme needs.
8. **Accessibility** — tokenless means any citizen with a phone/laptop works; fallback physical card for non-digital users (both modes, like Estonia's card + Smart-ID).
