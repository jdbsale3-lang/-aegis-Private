## 1. THE ONE-IDENTITY PRINCIPLE
Every citizen holds ONE NHS identity (card + ZEUS DOC digital twin). Every NHS setting — from GP surgery to ambulance to pharmacist — authenticates that identity with the same technology, signs consent with the same threshold signature, and reads/writes the same consent-ledger. No citizen ever re-proves who they are; every setting trusts the same root.

## 3. THE EQUIPMENT EVERY SETTING NEEDS (unified, minimal)

| **Wristband QR printer** | Admitted patients | £250–£500/ward | Hospitals |
| **ZEUS middleware** — reader driver + auth client | Software on every NHS-managed device | Licence (part of programme) | All settings |
| **Offline emergency module** | Card chip readable without network (standard smartcard applet) | Built into card | All settings |
| **Point-of-care terminal** (existing NHS device + ZEUS app) | Most settings already own PCs — we only add reader + software | Reader cost only | Everywhere |

**Key cost insight:** the NHS already owns the PCs/tablets/phones. ZEUS equipment = reader + software per workstation + card per citizen. No per-setting server required — everything else runs on the national back-end (Section "servers").
