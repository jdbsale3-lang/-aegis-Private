# ZEUSTA BRAND SPEC — SHOPIFY STOREFRONT
**Version 1.0 · 30 Aug 2026 · All IP belongs to JDB Sales**

## Palette
| Token | Hex | Use |
|---|---|---|
| Obsidian | `#10131B` | background, dark sections, hero |
| Obsidian 2 | `#1B2030` | panels, cards |
| Holographic Cyan | `#4FCEE4` | primary accent, buttons, links, icons |
| Cyan Deep | `#2FA8C3` | gradients, hover |
| Acid Yellow | `#D9F24B` | high-energy accents, badges, CTAs, limited use |
| White | `#FFFFFF` | headings, text on dark |
| Muted | `#9AA0AC` | secondary text |

## Typography
- Headings: **Archivo / Inter Black** (bold, tight tracking) — system fallback Helvetica/Arial
- Body: **Inter / Arial** regular, 16-18px, line-height 1.6
- Mono (prices/codes): JetBrains Mono / Courier

## Logo variants (in `zeusta-brand/`)
1. `zeusta-logo-master.svg` — full lockup (hex shield + wordmark + tagline) for header/footer, light use on dark
2. `zeusta-social-square.svg` — squircle logomark for store avatar, favicon, socials (use Obsidian bg version or inverse)

## Voice
"Trust, engineered." — calm, precise, security-grade. Short declarative sentences. No hype words like "ultra/revolutionary". Guarantee ethos: "Every product is AI-guarded and delivered digitally, instantly."

## Storefront rules
- Dark theme (Obsidian) as base — never white-heavy
- Cyan = interactive; Yellow = ONE hero CTA per view (Add to Cart / Subscribe)
- Product imagery: consistent dark backdrop + cyan glow + acid accent (same system as covers)
- All branding files live in repo `docs/security/zeusta-brand/`
